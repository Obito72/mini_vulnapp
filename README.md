# 🔓 Mini Vulnerable Web App

A simple and intentionally vulnerable PHP web application for practicing and demonstrating common web application security issues such as SQL Injection, File Upload Vulnerabilities, and more.

> ⚠️ **Warning**: This project is purposefully insecure and should be used **only in a controlled local environment** for educational purposes. **Do not deploy to production.**

---

## 📌 Features

- 🔐 **Login System** — vulnerable to SQL Injection
- 🧭 **Dashboard Page** — basic authenticated area
- 📁 **File Upload** — no restriction or validation
- 💡 Designed for hands-on cybersecurity learning
