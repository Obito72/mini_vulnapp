# 🛡️ Mini Vulnerable WebApp

A lightweight intentionally vulnerable web application for practicing web application security testing techniques.

---

##  Features

- 🕵️ SQL Injection Vulnerability on Login
- 💬 Cross-Site Scripting (XSS) on Comments
- 🔄 Cross-Site Request Forgery (CSRF) on Password Change
